# Logo Assets README (Public)

## Where Logo Files Should Live
- Place canonical logo files in: `branding/assets/`
- Keep this directory as the single source for public brand asset references.

## Naming Convention
Recommended naming pattern:
- `hit-logo-horizontal-color.png`
- `hit-logo-horizontal-color.svg`
- `hit-logo-stacked-color.png`
- `hit-logo-stacked-color.svg`
- `hit-mark-color.png`
- `hit-mark-color.svg`
- `hit-logo-horizontal-mono-black.png`
- `hit-logo-horizontal-mono-white.png`

Guidelines:
- Use lowercase kebab-case.
- Include lockup orientation (`horizontal`, `stacked`, `mark`).
- Include color mode (`color`, `mono-black`, `mono-white`).
- Include extension-specific source files (`.svg`) plus usage exports (`.png`).

## Usage Guidance
- Prefer full-color logos on light neutral backgrounds.
- Use mono variants only when production constraints require it.
- Preserve clear space and do not distort, recolor, or add effects.
- Maintain consistent rendering quality across docs and presentations.

## Important Scope Note
Logo files are **brand assets**, not app implementation files. This public repository documents brand direction and strategy; it does not include application build logic or private product code.
