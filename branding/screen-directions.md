# Humanities in Tech — Screen Directions (Public)

## 1) Landing Page
**Purpose**
- Communicate who the product is for and what problem it solves.

**Visual direction**
- Clean hero with concise value proposition.
- Light background, strong typography hierarchy, restrained color accents.
- Social proof placeholders (e.g., outcomes language without inflated claims).

**Primary user action**
- Start CV optimisation flow.

**What to avoid**
- Buzzword-heavy copy, cluttered feature grids, and hype claims.

## 2) Login / Sign Up
**Purpose**
- Fast, low-friction account entry.

**Visual direction**
- Minimal card layout with clear fields and a single dominant CTA.
- Helpful microcopy for reassurance and privacy expectations.

**Primary user action**
- Create account or sign in.

**What to avoid**
- Multi-step complexity before users understand product value.

## 3) Dashboard / Application Home
**Purpose**
- Orient users and show next best action.

**Visual direction**
- Progress-oriented layout: resume status, active target role, recent outputs.
- Calm cards, subtle borders, limited color accents.

**Primary user action**
- Continue or start a new optimisation session.

**What to avoid**
- Data-dense analytics dashboards that distract from core workflow.

## 4) Resume Upload / Paste Resume
**Purpose**
- Capture base candidate material quickly.

**Visual direction**
- Two clear input paths: upload file or paste text.
- Plain-language tips for formatting and completeness.

**Primary user action**
- Submit resume content.

**What to avoid**
- Overly technical parsing language or intimidating validation states.

## 5) Job Listing Input
**Purpose**
- Capture target role context for tailored outputs.

**Visual direction**
- Structured input area for job URL or pasted listing text.
- Optional role-level and company context prompts.

**Primary user action**
- Submit target role details.

**What to avoid**
- Excessive required fields that slow momentum.

## 6) Follow-up Questions
**Purpose**
- Fill critical context gaps before generation.

**Visual direction**
- Step-by-step question cards with progress indicator.
- Human, coaching-style phrasing.

**Primary user action**
- Answer targeted follow-up questions.

**What to avoid**
- Interrogation-like form tone or too many long free-text prompts.

## 7) Results Page (CV + Cover Letter + Gaps)
**Purpose**
- Present actionable outputs and rationale.

**Visual direction**
- Tabbed or sectioned output layout:
  1. Rewritten CV
  2. Draft cover letter
  3. Missing-information checklist
  4. Positioning/gap note
- High contrast body text with clear scan points.

**Primary user action**
- Review, refine, and accept outputs.

**What to avoid**
- Black-box outputs with no explanation of gaps or assumptions.

## 8) Export / Download PDF
**Purpose**
- Help users leave with polished, usable application artifacts.

**Visual direction**
- Simple export panel with format options and brief quality checklist.
- Confirmation state showing what was exported.

**Primary user action**
- Download final CV and cover letter as PDF.

**What to avoid**
- Hidden export controls or unclear file naming.
