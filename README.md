# Humanities in Tech

Humanities in Tech is a public portfolio record of product strategy and brand direction for a niche AI-powered CV and cover letter optimiser. The product concept is focused on helping humanities and nontraditional candidates translate their experience into credible tech and tech-adjacent applications.

## My Role & Contribution

I led and documented:
- Product positioning
- MVP scoping
- Brand strategy
- Visual direction
- Design-token system
- Screen-by-screen UX direction
- High-level prompt and methodology direction (public-safe only)
- Go-to-market framing

## What’s Included in This Public Repo

- Public-safe brand guide
- Design token documentation
- Screen-level UX direction for the MVP journey
- Logo asset handling guidance
- Product strategy case-study summary

## What’s Intentionally Excluded

- Private prompts and prompt libraries
- Golden-set CV pattern data and detailed methodology
- User data and internal research artifacts
- App implementation code from private repositories
- Infrastructure/configuration details (API keys, env vars, DB schemas)

> “This public repo contains sanitized brand and product strategy materials only. Proprietary prompts, golden-set CV patterns, user data, and implementation code are intentionally excluded.”

## Public-Sanitized Scope Note

This repository is a sanitized, portfolio-friendly record designed for recruiters, collaborators, and technical partners. It is not the private product-brain repository and not the production app codebase.
